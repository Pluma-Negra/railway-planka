# Planka on Railway

Quick deployment of **Planka** on Railway. A free and open-source Trello alternative for project management.

## What is Planka?

Planka is an open-source project management tool similar to Trello. Create boards, organize tasks with cards, collaborate with your team, and manage projects efficiently without third-party dependencies.

## Features

- 🚀 Quick deployment on Railway
- 📋 Kanban-style board management
- 👥 Real-time team collaboration
- 🎨 Customizable boards and cards
- 💾 Integrated PostgreSQL database
- 🔐 Self-hosted and secure

## Quick Start

1. Fork this repository
2. Connect your repository to Railway
3. Automatic deployment
